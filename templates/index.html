What this demo is not

Credentials are signed with HMAC-SHA256, a symmetric MAC. A production system would use ECDSA or EdDSA so verifiers need only a public key.

The status proof is a hash commitment, not a zk-SNARK. It hides the salt and the personal data, but it is not a general zero-knowledge circuit.
