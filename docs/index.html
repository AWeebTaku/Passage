Run it locally How it works

One round trip, from visa desk to border gate

  1. Issue

    The issuer signs the traveler record and anchors a commitment hash on DidRegistry.sol.

  2. Hold

    The wallet keeps the full credential and the blinding salt. Neither goes on-chain.

  3. Present

    The wallet hashes the claimed status with the salt and shows the result as text or a QR code.

  4. Verify

    Customs compares the hash to the commitment and reads revocation state from the chain.

What this demo is not

Credentials are signed with HMAC-SHA256, a symmetric MAC. A production system would use ECDSA or EdDSA so verifiers need only a public key.

The status proof is a hash commitment, not a zk-SNARK. It hides the salt and the personal data, but it is not a general zero-knowledge circuit.
